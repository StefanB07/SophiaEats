GET /restaurants - List all restaurants
GET /restaurants/filter?cuisine=Italian&price=$$ - Filter restaurants
GET /restaurants/Le%20Resto - Get restaurant by name
GET /delivery/locations - Get delivery locations
GET /delivery/slots?restaurant=Le%20Resto - Get delivery slots for restaurant

GET /users - List all users

GET /cart - Get cart for default/alice
POST /cart - Add item to cart (JSON)
POST /cart - Add item to cart (legacy pipe)
POST /cart/items - Add item to cart via /cart/items
GET /cart/delivery-options - Get cart delivery options

POST /orders - Create order (JSON)
POST /orders - Create order (legacy pipe)
GET /orders/{id} - Get order by id

GET /health (8081) - Catalog service health
GET /health (8082) - Order service health
